# 手办图库（Figure Gallery）

本仓库用于研究和规划一个可按角色搜索的正版比例手办和景品图库。

## 当前阶段

当前仅进行数据源验证与技术可行性验证，包括记录研究结论、保存小型脱敏证据，以及开展可丢弃的技术验证。

技术栈尚未确定。在完成研究与技术选型前，禁止初始化或搭建正式产品、正式应用或生产环境。

BOOTSTRAP-00 只建立仓库治理和研究目录，不开展 Hpoi 调研，不选择技术栈，也不搭建正式项目。

## 目录说明

- `research/`：研究结论与分析文档。
- `research/evidence/`：支撑研究结论的小型、脱敏证据。
- `spikes/`：可随时丢弃的技术验证。
- `docs/`：项目治理、设计及其他说明文档。

## 当前非目标

- 不开展正式产品开发。
