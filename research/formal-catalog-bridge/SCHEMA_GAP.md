# Formal Catalog Bridge schema gap

The frozen local projection contains two characters, 290 catalog items, 227 figure prototypes, 348 derivable source records, and 1,326 image references. The existing PR-01 schema cannot represent this dataset losslessly, but the gap fits the task's narrow scope gate.

| Validated local concept | Current formal representation                                            | Keep                                                                                                                      | Extend                                                                                                           | Add                                                                                               | Do not use yet                                                                              |
| ----------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Character               | `characters` Collection with internal stable UUID                        | Existing Character identity and lifecycle fields                                                                          | None; bridge resolves the unique existing `normalizedName` or creates the two missing draft records              | None                                                                                              | Work and full alias lifecycle                                                               |
| SourceRecord            | No formal representation                                                 | Exact public source URL, source family, source label/role, character and catalog-item ownership                           | None                                                                                                             | One `source-records` Collection with immutable URL-derived key and bridge business digest         | Candidate/Review workflow and fabricated source-specific title/manufacturer/image ownership |
| CatalogItem             | No formal representation                                                 | Source-independent item key, reliable collector fields, prototype membership, character ownership, and embedded ImageRefs | None                                                                                                             | One `catalog-items` Collection; each row belongs to exactly one Character and one FigurePrototype | FigureVersion, canonical Manufacturer mapping, price/stock lifecycle                        |
| FigurePrototype         | Existing `figure-prototypes` Collection and prototype-character relation | Existing UUID, lifecycle state, and Character relation                                                                    | Add immutable `projectionKey`, `membershipFingerprint`, nullable Manufacturer relation, and `static` figure type | None                                                                                              | New prototype schema, merge/split/undo, eligibility/publication changes                     |
| ImageRef                | No formal media representation                                           | Exact remote URL, source family, CatalogItem key, deterministic image key, main-image flag                                | None                                                                                                             | Embedded array owned by CatalogItem                                                               | Media Collection, S3 download, or a fabricated ImageRef-to-SourceRecord relation            |

## Scope gate

- New Collections: **2** (`source-records`, `catalog-items`).
- Important FigurePrototype extensions: **4**.
- Legacy schema mismatch: **yes** — current required Manufacturer and two-value figure type cannot represent the validated projection without loss.
- Scope exceeded: **no**.
- `SCHEMA_GAP_BLOCKED`: **false**.

The bridge will use a dedicated internal Payload Local API service, the existing private catalog write capability, and one import summary operation. It will not add an HTTP/Admin surface, rewrite the command framework, create formal media, or import any excluded collector rows.
