# Hpoi 数据源可行性验证（VAL-01）

## 结论摘要

- **测试窗口**：2026-07-12—2026-07-14（Asia/Shanghai）
- **Hpoi 可行性评级**：**低**（VAL-01B 更新；针对自动候选采集。人工浏览价值不在此评级内）
- **采集方式四选一结论**：**Hpoi 当前不适合作为稳定主数据源**。
- **推荐采集方式**：**不进入 Hpoi 自动化采集**。公开用户协议要求自动程序/脚本获取平台服务、内容或数据前取得事先明确书面许可；未取得并记录许可前，只作人工参考。
- **核心依据**：Python `requests` 直连已取得并解析 3 个真实商品页和 3 个真实角色页，但 curl 的 Schannel 路径失败；公开规则触发停止条件后，代理与图片请求均未执行。技术 HTML 子门禁成功，整体真实公开采集门禁因站点规则明确限制而未通过。

这不是对 Hpoi 内容正确性、授权状态或长期可用性的背书。采集结果只能进入候选池，不能自动修改正式数据或替换主图。

## VAL-01B 更新：真实传输与公开规则门禁

2026-07-14 在 Windows 本机按单并发、至少 2 秒间隔、固定 User-Agent 和 30 次硬上限执行有限测试。总计按最保守口径使用 **14/30** 次；没有登录、Cookie、Token、验证码规避、未公开 API 或永久代理设置。

| 验证点 | 实际结果 |
| --- | --- |
| 直连 HTML | `requests` 对固定的 3 个商品页与 3 个角色页均返回 200；curl 对 3 个商品页在 HTTP 前因 Schannel 证书吊销检查离线失败，未关闭 TLS 校验 |
| 临时代理 | `127.0.0.1:7897` 正在监听，但读取公开协议后立即停止，因此没有发起代理 Hpoi HTTP |
| 真实解析 | 3 个商品页均解析出数字 ID、名称、角色、作品、制作、属性和比例；2 个解析出当前出货日；缓存页重复运行由 `new` 变为 `unchanged` |
| 页面结构 | 当前 DOM 使用 `.hpoi-infoList-item` 的 `span/p`；JSON-LD Product 嵌套在 WebPage `mainEntity`；探测器已作通用修正 |
| 图片 | 商品 HTML 暴露封面和缩略图入口，但停止条件发生后没有请求图片；真实图片字节成功数为 0，Referer、防盗链、格式、尺寸、SHA-256 和 aHash 均未执行 |

| 门禁结论 | **未通过**；Hpoi 后续定位为**仅人工参考**，直至取得书面许可并在新任务中重跑未完成门禁 |

## 角色下商品发现与过滤

### 已验证能力

- 商品 URL 含稳定数字 ID，例如 `98369`、`80002`，可作为候选幂等键。
- 搜索结果与商品页公开显示“属性”，可见 `比例人形`、`Q版人形`、`GK`、`未上色`、`需拼装` 等标签。
- 商品页可显示“比例”“制作”“角色”“作品”“出货日”及“进程”时间线。
- 搜索结果确实混合比例、景品、黏土人、figma、GK 和其他类型，必须使用分类标签、系列/厂商和人工规则过滤。
- 商品页时间线可出现制作决定、预订、延期、出荷等事件；未验证“取消”是否有统一、可机器读取的状态。

### 不能据此自动决定的事项

- “景品”没有在本轮证明为统一结构化类别，可能依赖系列、厂商、标题或标签组合。
- `GK` 标签能帮助排除部分对象，但不能证明“正式授权第三方”与“未授权 GK”的授权状态；必须由厂商官网、会员购或人工证据补充。
- 普通版、豪华版、再版、特典版和纯异色版的“同原型归并”不是单一来源字段可以可靠决定的，需要人工审核和可撤销归并记录。
- 关键词分页可能因别名、错译、编辑变化或排序变动产生漏项/重复；只有来源 ID 能可靠对应已经发现的候选记录。

### 发售与制作状态识别

| 目标状态 | 本轮观察 | 阶段结论 |
| --- | --- | --- |
| 预售/预订 | 商品时间线可见“预订时间”和预计出荷月份 | 可取得但不稳定；需保留原文事件，不能直接假定统一枚举 |
| 已发售 | 样本商品可见“出货日/出荷时间” | 可取得但不稳定；延期、再版和多版本会形成多条事件 |
| 延期 | 柴郡和蕾姆样本时间线可见延期事件 | 可取得但不稳定；应作为事件而非覆盖原日期 |
| 灰模/未上色 | 搜索与条目标记中可见“未上色”信号 | 可取得但不稳定；未验证它是否稳定等同于“完整灰模” |
| 彩模 | 页面图片可供人工观察，但未发现经验证的统一结构化“彩模”状态 | 当前无法验证 |
| 取消 | 本轮有限样本未观察到可验证的统一取消状态 | 当前无法验证 |

## 幂等候选探测结论

`spikes/hpoi_probe/` 只保存候选快照和测试：

1. 首次运行将 `hpoi:id:98369` 报告为新候选；
2. 重复运行报告 `unchanged`，没有重复新增；
3. 唯一键优先 `source_type + source_item_id`；
4. 缺少 ID 时才使用去 fragment、去跟踪参数、排序查询参数后的 URL；后续获得稳定 ID 时迁移旧键，第二次不会误报新商品；
5. 变化样本输出发售日期、状态、图片内容/URL 和语义快照哈希差异；
6. VAL-01 原有 15 项和 VAL-01B 新增测试合计 30 项全部通过；中间代理继承和测试域白名单失败均已记录并修正；
7. 没有正式业务模型、数据库或应用框架；
8. 不读取 Cookie、Token 或账号登录状态，图片请求默认只允许 `rfx.hpoi.net`。

## 风险与明确阻塞项

1. **站点书面许可**：公开用户协议要求自动程序/脚本获取平台服务、内容或数据前取得事先明确书面许可；这是当前首要停止项。
2. **客户端差异**：requests 真实 HTML 直连成功，curl Schannel 因证书吊销检查离线而没有取得 HTTP；没有通过关闭 TLS 校验绕过。
3. **图片访问**：VAL-01B 因公开规则停止而没有请求 `rfx.hpoi.net`；原图发现、Referer、防盗链、保存与真实哈希均未验证。
4. **角色全集**：角色页“查看更多”与关键词分页不能证明完整、无漏项的角色关系集合。
5. **授权判断**：Hpoi 标签不足以自动确认第三方正式授权；必须补充厂商/会员购证据并人工确认。
6. **状态归一化**：时间线可读但没有验证统一 API/枚举；彩模和取消当前无法验证，灰模信号仍需规则与人工判断。
7. **登录边界**：公开字段可读，但站点明确宣传登录后高清大图；本任务禁止登录，因此高清链路不纳入可行结论。
8. **官图选择器**：真实 HTML 已验证媒体入口，但 `/gk/pic/` 可能同时含官图和用户图；不得把每个媒体 URL 自动视为官方候选图。
