# Hpoi 数据源可行性验证（VAL-01）

## 结论摘要

- **测试窗口**：2026-07-12—2026-07-13（Asia/Shanghai；最终复核与测试在 7 月 13 日零点后完成）
- **Hpoi 可行性评级**：**中**（适合作为继续验证的发现索引；当前不适合作为稳定主数据源）
- **采集方式四选一结论**：**Hpoi 当前不适合作为稳定主数据源**。
- **推荐采集方式**：在解决公开 HTTP 连通性并确认站点允许的访问边界前，**不进入自动化采集**。若后续门禁通过，优先验证低频 HTTP/HTML 解析；浏览器只作为人工核验或必要补充，不应成为高频采集器。
- **核心依据**：公开搜索、角色页和商品页含有丰富字段、稳定数字 ID、类型标签和多图入口；但本机普通 HTTP 超时、浏览器连接不可用、三个图片小样本均未取得字节、总数/分页完整性和公开接口均未得到可靠验证。

这不是对 Hpoi 内容正确性、授权状态或长期可用性的背书。采集结果只能进入候选池，不能自动修改正式数据或替换主图。

## 公开入口与角色定位

Hpoi 提供公开搜索页，输入框提示支持“关键字/条目 ID/JAN 码”，并提供“角色/要素、作品、厂商”等结果类型和手办分类筛选。公开页面无需登录即可读取核心资料；登录提示主要指向收藏、评论和“高清大图”等功能。

### 为什么没有报告“角色下手办总数”

搜索页面显示分页末页，但没有给出经过角色关系、类别和授权范围过滤后的明确总数。侧栏的年份与厂商数字不能证明是互斥、完整计数；关键词结果还包含同名角色、GK、Q 版、可动和其他非首批类型。因此，本轮只把 **2/16/43 页**记录为复核时的规模与分页信号，不把它们换算为完整手办总数。

## 角色下商品发现与过滤

### 已验证能力

- 商品 URL 含稳定数字 ID，例如 `98369`、`80002`，可作为候选幂等键。
- 搜索结果与商品页公开显示“属性”，可见 `比例人形`、`Q版人形`、`GK`、`未上色`、`需拼装` 等标签。
- 商品页可显示“比例”“制作”“角色”“作品”“出货日”及“进程”时间线。
- 搜索结果确实混合比例、景品、黏土人、figma、GK 和其他类型，必须使用分类标签、系列/厂商和人工规则过滤。
- 商品页时间线可出现制作决定、预订、延期、出荷等事件；未验证“取消”是否有统一、可机器读取的状态。

### 不能据此自动决定的事项

- “景品”没有在本轮证明为统一结构化类别，可能依赖系列、厂商、标题或标签组合。
- `GK` 标签能帮助排除部分对象，但不能证明“正式授权第三方”与“未授权 GK”的授权状态；必须由厂商官网、会员购或人工证据补充。
- 普通版、豪华版、再版、特典版和纯异色版的“同原型归并”不是单一来源字段可以可靠决定的，需要人工审核和可撤销归并记录。
- 关键词分页可能因别名、错译、编辑变化或排序变动产生漏项/重复；只有来源 ID 能可靠对应已经发现的候选记录。

### 发售与制作状态识别

| 目标状态 | 本轮观察 | 阶段结论 |
| --- | --- | --- |
| 预售/预订 | 商品时间线可见“预订时间”和预计出荷月份 | 可取得但不稳定；需保留原文事件，不能直接假定统一枚举 |
| 已发售 | 样本商品可见“出货日/出荷时间” | 可取得但不稳定；延期、再版和多版本会形成多条事件 |
| 延期 | 柴郡和蕾姆样本时间线可见延期事件 | 可取得但不稳定；应作为事件而非覆盖原日期 |
| 灰模/未上色 | 搜索与条目标记中可见“未上色”信号 | 可取得但不稳定；未验证它是否稳定等同于“完整灰模” |
| 彩模 | 页面图片可供人工观察，但未发现经验证的统一结构化“彩模”状态 | 当前无法验证 |
| 取消 | 本轮有限样本未观察到可验证的统一取消状态 | 当前无法验证 |

## 商品字段可获得性矩阵

状态枚举严格使用任务指定的五类。

| 字段 | 状态 | 证据与限制 |
| --- | --- | --- |
| `source_type` | 稳定可取得 | 由采集端固定写入 `hpoi`，不是页面字段 |
| `source_item_id` | 稳定可取得 | 商品 URL 中有数字 ID，如 `98369`、`80002` |
| `source_url` | 可取得但不稳定 | 同一条目可见 `/hobby/` 与 `/move/hobby/` 路径，需要保存规范化 canonical URL |
| `raw_title` | 稳定可取得 | 商品页公开“名称/中文名称” |
| `raw_character_names` | 可取得但不稳定 | 公开“角色”和角色标签；别名与多人商品需要保留原值 |
| `raw_work_name` | 可取得但不稳定 | 多个样本公开“作品”，但不能保证所有历史条目完整 |
| `raw_manufacturer` | 可取得但不稳定 | 商品页公开“制作”；用户编辑内容可能变更或缺失 |
| `raw_category` | 可取得但不稳定 | “属性”和搜索分类可区分比例/Q版/GK 等，但“景品”统一性未验证 |
| `raw_scale` | 可取得但不稳定 | 有 `1/7` 等字段；非比例条目可能为 `Non` 或缺失 |
| `raw_release_status` | 可取得但不稳定 | “进程”时间线可推导制作决定、预订、延期、出荷；未验证统一状态字段或取消状态 |
| `raw_release_date` | 可取得但不稳定 | “出货日/进程”公开但会延期和修订，应保留历史差异 |
| `homepage_image` | 可取得但不稳定 | 页面暴露 `rfx.hpoi.net` 缩略图 URL；查询参数和封面可能更新，字节下载未验证 |
| `candidate_images` | 可取得但不稳定 | 商品页展示多张“官图”入口；公开可见数量与高清原图访问边界未验证 |
| `collected_at` | 稳定可取得 | 由采集端使用 UTC 时间生成 |
| `raw_snapshot` | 当前无法验证 | 普通 HTTP 超时，未取得可提交的真实原始 HTML；本轮只验证了代表性小夹具 |

## 采集方式比较

| 方式 | 本轮证据 | 阶段结论 |
| --- | --- | --- |
| 普通 HTTP 请求 | 无登录 GET 超时 | 当前不可用；需要在 VAL-02 前先验证网络、响应头、频率和条款边界 |
| HTML 解析 | 代表性小型字段夹具与单元测试通过 | 解析能力可行，但不能宣称真实 Hpoi HTML 结构已验证 |
| 页面公开结构化数据 | Web 通道能抽取公开字段 | 原始 JSON-LD/嵌入状态未验证，不能依赖 |

| 浏览器自动化 | 应用内浏览器与 Chrome 连接均不可用 | 未执行成功；不应把失败描述为站点需要浏览器 |
| HTTP＋浏览器组合 | 两个必要通道没有同时可用 | 当前无法验证 |

## 幂等候选探测结论

`spikes/hpoi_probe/` 只保存候选快照和测试：

1. 首次运行将 `hpoi:id:98369` 报告为新候选；
2. 重复运行报告 `unchanged`，没有重复新增；
3. 唯一键优先 `source_type + source_item_id`；
4. 缺少 ID 时才使用去 fragment、去跟踪参数、排序查询参数后的 URL；后续获得稳定 ID 时迁移旧键，第二次不会误报新商品；
5. 变化样本输出发售日期、状态、图片内容/URL 和语义快照哈希差异；
6. 最终 15 项单元测试全部通过；中间代理继承和测试域白名单失败均已记录并修正；
7. 没有正式业务模型、数据库或应用框架；
8. 不读取 Cookie、Token 或账号登录状态，图片请求默认只允许 `rfx.hpoi.net`。

## 风险与明确阻塞项

1. **普通 HTTP 连通性**：本机对 Hpoi 商品页超时，无法验证真实 HTML、响应头、robots 或频率限制。
2. **图片访问**：`rfx.hpoi.net` 的三个角色小样本均未成功读取（403、重定向循环或超时），原图发现、防盗链、保存与真实哈希均未验证。
3. **角色全集**：角色页“查看更多”与关键词分页不能证明完整、无漏项的角色关系集合。
4. **授权判断**：Hpoi 标签不足以自动确认第三方正式授权；必须补充厂商/会员购证据并人工确认。
5. **状态归一化**：时间线可读但没有验证统一 API/枚举；彩模和取消当前无法验证，灰模信号仍需规则与人工判断。
6. **登录边界**：公开字段可读，但站点明确宣传登录后高清大图；本任务禁止登录，因此高清链路不纳入可行结论。
7. **站点稳定性与许可**：未完成服务条款、robots 与长期低频访问政策确认；自动化之前必须先解决。
8. **真实 DOM 与官图选择器**：本轮解析测试使用手工缩减夹具；未取得真实 HTML，尚不能可靠排除页面图标、头像、评论图或用户图，因此不得把完整页面的所有 `<img>` 自动当作官方候选图。
